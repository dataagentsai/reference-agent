## Partial-discharge caveats on tags I added

- `AHC-0053` rests entirely on a non-durable delivery log (see test_trigger).
- `AHC-0044`: checkpoints are per turn, not per loop step. Replay without re-executing
  writes is untested. `test_a_turn_is_checkpointed` uses the in-memory store; it is
  tagged because it's the only test showing the entrypoint writes a checkpoint at all.
- `AHC-0023`: configuration half only; no capture date, no re-cut command.
- `AHC-0039`, `AHC-0094`: classification / position exist and act; the dispatch grant
  and the block→refused-outcome mapping are not asserted in these files.
- `R-DISCOUNT` / `esc:asked-for-human` share one parametrized function, so each case
  also carries the other case's id.
